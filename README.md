# InterviewHub

**InterviewHub** is a professional interview preparation platform tailored for IT students, fresh computer science graduates, and junior software developers.

## 🎯 Purpose & Goals
Preparing for technical software engineering interviews often feels overwhelming and fragmented. **InterviewHub** provides a structured, high-yield preparation ecosystem featuring:
- Categorized question bank spanning Frontend, Backend, CS Fundamentals, SQL, System Design, and Soft Skills.
- In-depth answer breakdowns with code syntax highlighting and interview key points.
- Interactive flashcard and timed quiz practice modes.
- Personal progress tracking, bookmarks, daily streaks, and weak topic detection.

---

## 🛠️ Current Technology Stack
- **Framework**: [React 18/19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/) (Strict mode enabled)
- **Styling**: [Tailwind CSS v3](https://tailwindcss.com/) + PostCSS + Autoprefixer
- **Code Quality**: [ESLint](https://eslint.org/) + [Prettier](https://prettier.io/)
- **Version Control**: Git

## 📦 How to Install Dependencies

Ensure Node.js (v18+) is installed on your machine.

```bash
# Clone repository (if applicable) and navigate to workspace
npm install
```

---

## 💻 How to Run the Project Locally

```bash
# Start local development server (with HMR)
npm run dev

# Run TypeScript type check
npm run typecheck

# Run ESLint check
npm run lint

# Format code with Prettier
npm run format

# Create production build
npm run build

# Preview production build locally
npm run preview
```
